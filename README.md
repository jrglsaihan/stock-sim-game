# 📈 模拟炒股练习

一个用 **Python + Kivy** 编写的股票交易逻辑练习软件。

> ⚠️ **重要声明**：本程序**仅用于练习**，全程使用**完全虚拟的货币**，不涉及任何真实资金、真实账户、真实交易；**没有任何真实金融交易能力，不能对接券商实盘**；行情数据来自公开接口，仅供参考；**不构成任何投资建议**。股市有风险，投资需谨慎。

## 功能

- 3 种难度：简单（100 万）/ 困难（50 万）/ 地狱（30 万）初始虚拟资金
- 尽量对标 A 股规则：T+1、100 股整手、涨跌停限制、佣金/印花税/过户费
- 使用**真实当日行情**（腾讯公开接口），断网自动切换**离线模拟数据**
- 胜负判定：总资产 ≥ 1 亿元 → 挑战成功；总资产 ≤ 100 元 → 破产失败
- 暗色 UI、进度条、持仓/交易记录、自动存档

## 在 Mac 上运行（最简单）

1. 双击 `run.command`（首次会自动创建环境并安装 Kivy，约 1–2 分钟）。
   - 若提示“无法打开”：右键 `run.command` → 打开。

**或者用 VS Code：**

1. 用 VS Code 打开本文件夹（`stock-sim-game`）。
2. 直接按 `F5` 运行。

## 如何得到安卓 APK（自动打包，无需 Mac 装 Linux）

macOS 本地不能直接产出 APK（Buildozer 需要在 Linux 上运行），本项目已配置好 **GitHub Actions 自动打包**：

1. 把代码推送到你的 GitHub 仓库（首次推送需要登录一次 GitHub，见下）。
2. 打开仓库网页 → 顶部点 **Actions** → 左侧选「打包安卓 APK」→ 点 **Run workflow** → **Run workflow**（绿色按钮）。
3. 等约 15–40 分钟，构建完成后点进该次运行，在页面底部 **Artifacts** 处下载 APK。
4. 把 APK 传到手机，允许“安装未知来源应用”后安装。

> 也可以不手动点：每次向 `main` 分支推送代码，都会自动重新打包。

